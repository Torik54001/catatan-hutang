Agar data benar-benar berpindah antar-HP, aplikasi perlu database cloud. Siapkan Supabase Free satu kali, lalu gunakan URL, kunci publik, ID, dan PIN yang sama di kedua HP.
Gunakan kunci publik (anon/publishable), jangan pernah tempel service_role key.
Buat PIN yang hanya Anda ketahui. Masukkan PIN yang sama saat membuka dari HP lain. PIN tidak disimpan di perangkat.
Setup satu kali:
1. Buat project gratis di Supabase.
2. Tekan Salin SQL setup database, buka Supabase → SQL Editor → New query, tempel SQL, lalu Run.
3. Ambil Project URL dan Publishable/anon key dari Project Settings → API, lalu isi di atas.
4. Hubungkan HP pertama. Di HP kedua, buka file/aplikasi yang sama dan masukkan URL, key, ID, serta PIN yang sama.

ID hanya alamat akun database, bukan kata sandi. Jangan bagikan PIN atau kunci pribadi. Sinkronisasi memerlukan internet dan sebaiknya dibuka melalui alamat HTTPS; saat offline, catatan tetap disimpan di perangkat ini.
